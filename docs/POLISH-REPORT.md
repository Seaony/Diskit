## 风险与待决定

- 迅雷上传已按用户批准接入官方阿里云 SDK，但真实 STS、长文件、同名竞态、限流和空间不足仍需账号手验。接口仍是实验性网页 API，服务商更新后可能失效。
- WebDAV 的临时服务上 `NetFSMountURLAsync` 与 `mount_webdav` 行为不同，不能由本机单一探针判断所有真实服务。当前保留 NetFS 路线并等待真实服务验收。
- 所有正式 OAuth、网盘账号、Windows 共享、NFS、手机、相机和推送通知都需要外部环境；假实现测试不能替代这些验收。
- 最后一轮新增了实验网盘登录失效到“需要重新登录”的统一路径，系统通知的真实展示仍待用户允许通知后触发一次失效场景。
- 部分网盘跨目录改名由“移动”和“改名”两个服务端请求组成，接口没有事务。提交前已补失败后的缓存失效，但仍不能保证网络中断时远端两步同时成功；这类操作的行为与原计划一致，未把它写成原子操作。
