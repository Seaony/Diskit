# Kayoi 文案约定

## 核心术语

- **位置**：用户保存的一个设备、共享或网盘入口。界面统一写“位置”，例如“添加位置”“删除位置”“已保存的位置”。
- **连接**：只表示连接动作或连接状态，例如“测试连接”“正在连接”“连接设置”。不要把已保存的条目叫作“连接”。
- **共享**：只指 SMB、WebDAV 或 NFS 对外提供的目录。具体字段写“共享名”“选择共享”；网盘和设备不叫共享。
- **挂载 / 推出**：系统挂载卷进入 Finder 写“挂载”，离开 Finder 写“推出”。不要用“卸载”“断开挂载”等近义词指同一动作。
- **相机 / 手机 / 网盘**：指具体类型时优先用这些短词，不写成“设备位置”“网盘连接”等复合名词。

## 页面和操作

- 顶层动作统一为“添加位置”“编辑位置”“删除位置”。
- 主表单按钮统一为“测试并保存”，只读相机等无需测试的类型可按实际动作写“保存”。
- 重试动作写“重试”；登录失效时写“重新登录”。
- 取消授权、扫码或等待直接写“取消”，不要显示技术错误。
- 退出时取消正在进行的测试、登录和配对；保留 SMB、WebDAV、NFS 系统挂载。没有待处理操作时直接退出，不增加确认。

## 错误和提示

- 标题说明没有完成什么，正文说明原因，按钮给出可执行的下一步。
- 常见错误先写用户能理解的结果，例如“同名文件已存在”“没有访问权限”“服务请求过多，请稍后重试”。
- POSIX 错误码、HTTP 状态码和平台业务码只放进“详细信息”，不放在主提示里。
- 认证失败按类型区分：安卓写手机、相机写相机、网盘写登录；不要对所有类型都提示“允许 USB 调试”。
- `client_id`、`client_secret`、Cookie 名、回调地址等开发配置不进入普通用户界面。缺配置时写“此网盘尚未在 Kayoi 中启用”。

## 中英文

- 中文使用全角标点；中英文和数字之间留一个半角空格。
- 英文按钮和窗口标题使用 Title Case，说明与状态使用 Sentence case；完整句子结尾加句号，按钮和短标签不加句号。
- 产品名按官方写法保留，例如 OneDrive、Google Drive、Dropbox、WebDAV、SMB。
- 数量文案必须提供 String Catalog plural 变体；英文不得出现 `1 locations`。


## 中英文术语对照

| 中文 | 英文 |
| --- | --- |
| 位置 | Location |
| 我的位置 | My Locations |
| 已发现 | Discovered |
| 添加位置… | Add Location… |
| 测试连接 | Test Connection |
| 测试并保存 | Test and Save |
| 已连接 | Connected |
| 挂载 / 推出 | Mount / Eject |
| 共享 / 共享名 | Share / Share Name |
| 重新登录… | Sign In Again… |
| 设置步骤 | Setup Steps |
| 实验功能 | Experimental |
| 只读 | Read-Only |

## 目录与验收

- 应用词条属于 App 资源包；包内错误和状态词条属于 Core 资源包，命令行工具无需依赖主应用资源。
- 静态文案使用 `L`；带参数文案使用 `LF`，先选择复数再格式化。文件名、服务器返回内容等动态数据不作为目录键。
- `scripts/check-strings.sh` 检查实际使用键、闲置键、中英文翻译、格式参数和数字复数变体；新增文案后运行此检查。
- `KAYOI_DEMO=1 KAYOI_PSEUDO_LOCALE=1` 使用英文并增加约 40% 长度，仅影响演示进程；截图需检查换行、截断、按钮和错误详情。
- 普通提示依次说明发生了什么、原因和下一步；技术详情保留原始诊断。取消不显示失败，未知容量不显示为零。
- 只有 SMB、WebDAV、NFS 使用 Finder 系统挂载。其他类型在应用中测试连接，文件操作当前通过 `kayoi-dev` 使用；实验接口与真实设备、账号行为仍需用户验收。
