# Kayoi 0.2 设计基准

以 OPTIMIZATION.md 的编号规格为验收依据；本文件只记录落地规则，不替代截图验收。

## Design plan

- 形态：菜单栏快速面板、添加和网页登录独立窗口、系统设置窗口、可搜索帮助窗口。所有自绘表面不透明，不使用玻璃材质。
- 信息架构：面板依次为状态、已发现、我的位置、工具栏；设置五页为通用、通知、存储、安卓、关于；帮助按设备、共享、官方网盘、实验性网盘、对象存储组织。
- 命令：添加 ⌘N、编辑 ⌘E、删除 ⌫、设置 ⌘,、帮助 ⌘?、退出 ⌘Q；面板方向键选择、Return执行、Escape关闭。排序保留右键上移/下移。
- 空状态：面板保留单个添加主按钮和原创文件夹插图；搜索无结果显示清除搜索动作；没有历史缓存时如实显示无缓存，不暗示未实现的同步功能。
- 感受：平静、直接、可信。颜色表示状态与选择，不给卡片加装饰性绿底；短反馈服务于按下、插入和状态变化。

## 令牌

- 间距使用 Space 的4、8、12、16、20、24、32；窗口边距20。半径使用Radius.control/tile8和row/card12，连续圆角。
- 颜色全部来自Assets色集，提供浅色、深色、增强对比度浅色、增强对比度深色四个值。语义文本与按钮组合由ColorContrastTests逐一检查。
- 常规文案用系统body/subheadline/caption，不用裸字号；数值使用monospacedDigit。完整名称在tooltip保留。
- 用户8色与原创图标导出颜色基准一致；色名固定为blue、green、orange、red、purple、pink、teal、gray。
- 反馈120毫秒；减弱动态效果时禁用位移和缩放。焦点环只用于当前控件或选中行。

## 验收边界

颜色数值检查和源码分析不能证明视觉完成。浅深色、中英文、伪语言、窗口尺寸、键盘/VoiceOver、拖动和全部状态按OPTIMIZATION §14统一用演示模式Computer Use验收。
