# LanzouDrive

蓝奏云非官方网页接口的实验性只读 Provider。接口可能随网页改版或风控规则变化。

## 认证模型

- `LanzouAuthentication.accountCookie`：使用账号网页版 Cookie 读取账号目录。Cookie 只发往配置的账号站点。
- `LanzouAuthentication.share`：使用公开分享链接和可选密码。密码只在分享站点的下载参数中发送。
- 遇到 `acw_sc__v2` 浏览器验证时明确报错，不在客户端推算或绕过验证。

## 能力

- 支持账号目录和分享文件夹的分页列表。
- 支持下载直链的 HTTP Range，并校验 `206` 和 `Content-Range`。页面返回 `200` 时报告服务没有返回请求范围。
- 可写、改名、移动、删除能力全部声明为关闭，对应方法直接返回 `EROFS`。上传因此不会触网，也不会尝试改名、覆盖或处理同名旧文件。
- 鉴权失效、密码错误、限流、内容不存在和普通 HTTP 错误使用不同的 `LanzouError`，同时提供 POSIX 和 `RemoteError` 映射。

## 行为依据

接口行为参考 OpenList 与 AList 蓝奏云驱动当前的列表、分享页、密码参数、下载解析和分页语义。实现未复制其 AGPL 代码，也没有新增三方依赖或自写密码学代码。

真实账号、分享密码、浏览器验证和下载 Range 仍待用户用实际链接验收。
